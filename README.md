A one-page responsive portfolio built with plain HTML, CSS and JavaScript.

- `index.html` — page structure/content
- `style.css` — visual design/responsive styles
- `script.js` — animations and project modal

## Free hosting with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will give you a `https://YOUR-USERNAME.github.io/portfolio/` address.

For a cleaner address, name the repository `YOUR-USERNAME.github.io`; then the site is available at `https://YOUR-USERNAME.github.io/`.
